# Textos de la interfaz

## La regla

**Ningún texto que lea la persona usuaria va en la plantilla.** Todo sale
de `app/i18n/locales/` a través de `useTexto()`.

```vue
<script setup lang="ts">
const { t } = useTexto()
</script>

<template>
  <BaseEncabezadoPagina :titulo="t('disponibilidad.titulo')" />
</template>
```

## Dónde están

```text
app/i18n/
├── index.ts            Tipos y registro de idiomas
└── locales/
    ├── es.ts           Español: define las claves
    └── en.ts           Inglés: las mismas claves
```

- `es.ts` define las claves; de ellas sale el tipo `ClaveMensaje`.
- Cada idioma es un `Mensajes` con **todas** las claves de `es.ts`. Si
  falta una, el proyecto no compila.
- `index.ts` reúne los idiomas y exporta `ClaveMensaje`, `CodigoIdioma` y
  `IDIOMA_POR_DEFECTO`.

## Agregar un texto

1. **Primero en `es.ts`**, que define el tipo:

   ```ts
   'reservas.titulo': 'Reservas',
   'reservas.vacia': 'No hay reservas registradas.',
   'reservas.estados.pendiente': 'Pendiente',
   ```

2. **Después en los demás idiomas**, con la misma clave.
3. En la vista, con `t('reservas.titulo')`.

Las claves se ordenan por área, en el mismo orden que las páginas.

## Nombrar las claves

| Patrón | Ejemplo |
|---|---|
| `area.elemento` | `disponibilidad.columnas.cupo` |
| `area.estado` | `reservas.estados.pendiente` |
| `area.accion` | `comun.guardar` |
| `errores.*` | `errores.conexion` |

- Minúsculas, con puntos, sin acentos ni guiones.
- La clave describe **dónde** está el texto, no qué dice.
- Lo compartido va en `comun.*`; lo de un módulo, con su nombre delante.

## Valores con datos

```ts
'errores.conexion': 'No se pudo comprobar: {detalle}',
```

```ts
t('errores.conexion', { detalle: error })
```

Un marcador sin valor se deja como está, para que se note el error.

## Traducir

- Un idioma es un archivo en `locales/` con el nombre del código.
- Para agregar uno: copiar `es.ts`, traducir los valores y registrarlo en
  `idiomas`, en `index.ts`.
- El idioma en uso se guarda en una cookie (`idioma`), para que servidor y
  cliente coincidan al renderizar.

## Decisiones

| Caso | Decisión |
|---|---|
| Fechas y números | Se formatean con la configuración regional del idioma activo |
| Nombres propios | Vienen de la base; no se traducen |
| Errores del servidor | Se traducen por código; no se muestra el mensaje crudo |
| Textos de correo | Van en su propio archivo |

## Reglas

1. La clave se escribe primero en `es.ts`.
2. Ningún idioma queda con menos claves: el compilador lo avisa.
3. Una clave que ya no se usa se elimina de todos los idiomas.
4. Se traduce con el mismo contexto y el mismo tono.
