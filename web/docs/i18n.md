# Textos de la interfaz

## La regla

**Ningún texto que la persona usuaria lea va escrito en la plantilla.** Todo
sale de `app/i18n/locales/`, a través de `useTexto()`.

```vue
<script setup lang="ts">
const { t } = useTexto()
</script>

<template>
  <BaseEncabezadoPagina :titulo="t('disponibilidad.titulo')" />
</template>
```

## Dónde están

```text
app/i18n/
├── index.ts            Tipos y registro de idiomas
└── locales/
    ├── es.ts           Español: define las claves
    └── en.ts           Inglés: traducción con las mismas claves
```

- `es.ts` es el archivo que **define las claves**: de sus claves sale el
  tipo `ClaveMensaje`.
- Cada idioma es un `Mensajes`, es decir, un objeto con **todas** las
  claves de `es.ts`. Si falta una, el proyecto no compila.
- `index.ts` reúne los idiomas y exporta `ClaveMensaje`, `CodigoIdioma` y
  `IDIOMA_POR_DEFECTO`.

## Agregar un texto

1. **Primero en `es.ts`**, que es el que define el tipo:

   ```ts
   'reservas.titulo': 'Reservas',
   'reservas.vacia': 'No hay reservas registradas.',
   'reservas.estados.pendiente': 'Pendiente',
   ```

2. **Después en los demás idiomas**, con la misma clave.

3. En la vista, con `t('reservas.titulo')`.

El orden de las claves dentro de `es.ts` es por área, y las áreas están en
el mismo orden que las páginas.

## Nombrar las claves

| Patrón | Ejemplo |
|---|---|
| `area.elemento` | `disponibilidad.columnas.cupo` |
| `area.estado` | `reservas.estados.pendiente` |
| `area.accion` | `comun.guardar` |
| `errores.*` | `errores.conexion` |

- Minúsculas, con puntos, sin acentos ni guiones.
- La clave describe **dónde** está el texto, no qué dice.
- Los textos compartidos por toda la aplicación van en `comun.*`.
- Los textos de un módulo se anteponen con el nombre del módulo.

## Valores con datos

Los marcadores entre llaves se sustituyen:

```ts
'errores.conexion': 'No se pudo comprobar: {detalle}',
```

```ts
t('errores.conexion', { detalle: error })
```

El marcador que no se encuentre en los valores se deja como está, para que
se note el error.

## Traducir

- Un idioma es un archivo en `locales/`, con el nombre del código.
- Para agregar un idioma: copiar `es.ts` con el nombre nuevo, traducir los
  valores y agregarlo a `idiomas` en `index.ts`.
- El idioma en uso se guarda en una cookie (`idioma`), de modo que el
  servidor y el cliente coinciden al renderizar.

## Casos que conviene decidir de antemano

| Caso | Decisión |
|---|---|
| Fechas y números | Se formatean con la configuración regional del idioma activo; no se escriben a mano |
| Nombres propios (paquetes, clientes) | Vienen de la base; no se traducen |
| Errores del servidor | Se traducen en la interfaz por código, no se muestra el mensaje crudo |
| Textos de correo o notificación | Van en su propio archivo, no en el de la interfaz |

## Reglas

1. La clave se escribe primero en `es.ts`.
2. Ningún idioma queda con menos claves que `es.ts`: el compilador lo
   avisa.
3. Una clave que ya no se usa se elimina de todos los idiomas a la vez.
4. Los textos de la interfaz no se traducen a ojo: se traducen con el
   mismo contexto y el mismo tono.
