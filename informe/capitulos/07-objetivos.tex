\capituloSinNumero{Objetivos}
\label{cap:objetivos}

\section*{Objetivo general}

Desarrollar un sistema web de gestión de reservas que mejore la consistencia
del proceso de venta de paquetes turísticos en Vizcacha Tours de la
ciudad de Potosí.

\section*{Objetivos específicos}

\begin{enumerate}
  \item Fundamentar teóricamente la gestión de reservas, el control de
        disponibilidad de paquetes turísticos y los criterios de diseño de
        sistemas web relacionados con la variable dependiente del proyecto.
  \item Diagnosticar el proceso actual de atención y confirmación de reservas
        en Vizcacha Tours mediante entrevistas, observación y revisión
        autorizada de documentos, para identificar las principales
        dificultades y necesidades de la agencia.
  \item Diseñar y elaborar los diferentes componentes de un sistema web que
        permita administrar paquetes, clientes, fechas y reservas, validar los
        cupos disponibles y generar información de apoyo para mejorar el
        proceso estudiado.
\end{enumerate}
