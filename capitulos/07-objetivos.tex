\chapter{Objetivos}
\label{cap:objetivos}

\section{Objetivo general}

Desarrollar un sistema web para la gestión de paquetes turísticos y reservas
que permita mejorar el control de disponibilidad de cupos y la confirmación
de viajes en una agencia de turismo de la ciudad de Potosí.

\section{Objetivos específicos}

\begin{enumerate}
  \item Fundamentar teóricamente la gestión de reservas, el control de
        disponibilidad de paquetes turísticos y los criterios de diseño de
        sistemas web relacionados con la variable dependiente del proyecto.
  \item Diagnosticar el proceso actual de atención y confirmación de
        reservas mediante entrevistas, observación y revisión autorizada de
        documentos, para identificar las principales dificultades y
        necesidades de la agencia.
  \item Diseñar, desarrollar y evaluar un sistema web que permita
        administrar paquetes, clientes, fechas y reservas, validar los cupos
        disponibles y generar información de apoyo para mejorar el proceso
        estudiado.
\end{enumerate}
