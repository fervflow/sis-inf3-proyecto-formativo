\chapter{Variables del proyecto}
\label{cap:variables}

\textbf{Variable independiente (VI):} sistema web para gestionar paquetes
turísticos y reservas, con funciones de consulta de disponibilidad,
validación de cupos, actualización de estados y registro de información
relacionada.

\textbf{Variable dependiente (VD):} consistencia y eficiencia del proceso de
reservas y del control de disponibilidad de paquetes turísticos. Se podrá
evaluar por la precisión de los cupos, la cantidad de inconsistencias y el
tiempo utilizado para comprobar y confirmar una reserva.
