\chapter{Límites del proyecto}
\label{cap:limites}

El desarrollo se limitará a Vizcacha Tours y a los paquetes que administra
directamente. No incluirá conexión automática con los sistemas de aerolíneas
ni con sistemas globales de distribución. Tampoco se desarrollará una
aplicación móvil nativa, aunque el sistema podrá abrirse desde un navegador de
celular.

No se implementarán facturación tributaria ni contabilidad completa. El
sistema permitirá registrar pagos en efectivo y simular pagos por banca móvil
o código QR, con fines de seguimiento administrativo, sin conectarse a
pasarelas bancarias reales. Para el desarrollo y las pruebas se utilizarán
datos ficticios o autorizados, de modo que no se exponga información personal
de los clientes. Se aplicarán medidas básicas de control de acceso y
protección de datos, tomando como referencia las recomendaciones de OWASP
Foundation \parencite{owasp2025}.
