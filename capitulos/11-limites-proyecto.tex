\chapter{Límites del proyecto}
\label{cap:limites}

El desarrollo se limitará inicialmente a una agencia de turismo y a los
paquetes que administra directamente. No incluirá conexión automática con
los sistemas de aerolíneas ni con sistemas globales de distribución.
Tampoco se desarrollará una aplicación móvil nativa, aunque el sistema
podrá abrirse desde un navegador de celular.

No se implementarán facturación tributaria, contabilidad completa ni
pasarelas de pago bancario reales en la primera versión. Los pagos se
registrarán con fines de seguimiento administrativo. Para realizar pruebas
se utilizarán datos ficticios o autorizados, de modo que no se exponga
información personal de los clientes.

La posibilidad de completar el diagnóstico dependerá del permiso de una
agencia, de la disponibilidad de sus trabajadores y del tiempo de la
materia. Se considerarán medidas básicas de control de acceso y protección
de datos, tomando como referencia las recomendaciones de seguridad para
aplicaciones web de OWASP Foundation \parencite{owasp2025}.
